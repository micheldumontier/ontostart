# Test ontology

A placeholder ontology with no terms of its own. It lets the first build run end to end. Rename the folder and file (`ontologies/<name>/<name>.ttl`) and edit the IRIs, or delete it once you have your own ontology.

Its IRI is `https://w3id.org/<w3id>/testo/`, where `<w3id>` is the name you gave to `ontostart init`.

Don't edit `versions/`: the build writes it.
