OntoStart is a GitHub Actions pipeline for OWL ontologies. Commit a Turtle file; it is checked, versioned, documented, assessed for FAIRness and published under a persistent IRI.

Use the template See the collection

The pipeline · runs on every push to main

  1. 01Commitontologies/<name>/<name>.ttl
  2. 02CheckOWL 2 DL profile with ROBOT, consistency with HermiT.
  3. 03VersionBump x.y.z; write ttl, owl, jsonld and nt.
  4. 04DocumentOntoSpy and pyLODE pages for every term.
  5. 05AssessA FOOPS! FAIRness report, and status badges.
  6. 06PublishGitHub Pages, a DCAT catalogue, a w3id.org IRI.

If a check fails, nothing is published and the run says why. The last good version stays online.

For teachers

A sandbox for class

Students publish under w3id.org/ontostart/sandbox/<name>/ with one pull request, no w3id.org request of their own. Classroom guide.

For groups and projects

Your own namespace

Start a collection from the template under your own w3id.org name, in your own repository.

Start now.

uvx --from git+https://github.com/micheldumontier/ontostart@v1.5 \
  ontostart init --w3id NAME --owner OWNER --repo REPO

Create a repository from ontostart-template, run this in it, and push.
